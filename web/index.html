Problem / Value

Katkı metrikleri ekran görüntüsü olmak zorunda değil.

Katkı raporları değiştirilebilir dosyalar ya da manuel beyanlar olarak kalmasın. Clichain; hash, onay eşiği, IPFS kanıtı ve soulbound rozet zinciriyle katkıyı doğrulanabilir hale getirir.

Deterministik Hash Aynı rapor, aynı kanıt parmak izini üretir.
Çoklu Onay Yetkili approver eşiği tamamlanmadan final durum oluşmaz.
Soulbound Badge Katkı rozeti kişiye bağlıdır, transfer edilemez.

Akış

Git geçmişinden zincir üstü rozete.

01Git geçmişini tara

Commit aralığı ve contributor verisi okunur.

02in-toto report.json üret

Katkı raporu standart Statement v1 formatına alınır.

03Hash hesapla ve IPFS'e yükle

Rapor Pinata/IPFS'e pinlenir, kanıt CID'i oluşur.

04Kontrata submit et

Rapor referansı ve hash zincire anchor edilir.

05Approver attest eder

Repo owner tarafından yetkilendirilen onaycılar imza verir.

06Finalize + badge mint

Threshold tamamlanınca soulbound badge üretilir.

Özellikler

Katkı kanıtı için uçtan uca MVP.

Registry Contract

Rapor hash'i ve durum takibi

Owner, threshold, report hash, URI ve final durum kontrat seviyesinde izlenir.

CLI Pipeline

scan, hash, submit, attest

Komut satırı akışı report üretiminden verify-chain doğrulamasına kadar çalışır.

Dashboard

Wallet, GitHub ve indexer

Repo/commit seçimi, report verification ve lightweight event stream tek ekrandadır.

Soulbound Badge

Transfer edilemeyen katkı rozeti

Onaylanan katkı metadata'sı okunabilir, rozet kullanıcıya bağlı kalır.
